# Dataset Documentation — Deepfake Detection System

## 1. Overview & Data Segregation Principles

To guarantee scientific validity and eliminate data leakage, the project enforces strict partitioning across all dataset sources.

```
┌────────────────────────────────────────────────────────────────────────┐
│                        DATASET PARTITIONS                              │
├────────────────────────┬───────────────────────┬───────────────────────┤
│    TRAINING DATA       │   CALIBRATION DATA    │   HELD-OUT TEST DATA  │
│  (For Model Learning)  │ (For Ensemble Weights)│  (🔒 SEALED EVALUATION) │
│                        │                       │                       │
│ • FFHQ Real Faces      │ • ~50 Real Smartphone │ • ~250 Real Smartphone│
│ • LFW Real Faces       │   Photos              │   Photos (Untouched)  │
│ • FaceForensics++ c23  │ • ~50 Benchmark Fakes │ • ~250 Known Fakes    │
│ • Celeb-DF v2 Fakes    │                       │   (Unseen sources)    │
│ • Albumentations       │                       │                       │
│   Degradation Pipeline │                       │                       │
└────────────────────────┴───────────────────────┴───────────────────────┘
```

> [!CAUTION]
> **Data Segregation Rule:** Images in `data/holdout/` must NEVER be exposed to the training loop, validation loss evaluation, or hyperparameter/ensemble tuning. The held-out test set is evaluated ONCE in Phase 7 to measure honest real-world generalization.

## 2. Legacy Datasets (Used for Baseline Checkpoint)

### A. 140k Real-vs-Fake Dataset
- **Source:** [Kaggle: 140k Real and Fake Faces Dataset](https://www.kaggle.com/datasets/xhlulu/140k-real-and-fake-faces)
- **Total Images:** 140,000 images (70,000 Real, 70,000 Fake)
- **Composition:**
  - **Real:** High-resolution human face crops from Flickr-Faces-HQ (FFHQ).
  - **Fake:** Synthetic human face images generated by StyleGAN.
- **Split:** 100,000 Train / 20,000 Validation / 20,000 Test
- **Limitations:** FFHQ contains studio-quality DSLR photos with professional lighting, crisp focus, and no social media compression. StyleGAN only represents one generative architecture (GAN-based synthetic generation), completely lacking face-swap or reenactment artifacts.

### B. CIFAKE Dataset (⚠️ Marked for Permanent Removal)
- **Source:** [Kaggle: CIFAKE Real vs AI Synthetic Dataset](https://www.kaggle.com/datasets/birdy666/cifake-real-and-ai-generated-synthetic-images)
- **Total Images:** 120,000 images (60,000 Real, 60,000 Synthetic)
- **Composition:** Real CIFAR-10 general object images (airplanes, horses, cars, dogs) vs Stable Diffusion v1.4 synthetic object images.
- **Image Resolution:** $32 \times 32$ pixels upscaled.
- **Verdict & Status:** **DROPPED.** Contaminates face detection boundaries because non-facial textures force the ViT to learn irrelevant background and object statistics.

## 4. Real-World Evaluation Dataset (Phase 2 Collection)

### A. User Collection Protocol
Collected with informed consent from friends, family, and diverse subjects using varied smartphone hardware.

| Category | Description | Target Count | Priority |
|---|---|---|---|
| **Indoor Good Light** | Living room, office, overhead/window illumination | 30–40 | High |
| **Indoor Low/Dim Light** | Evening, single lamp, screen reflection, party lights | 20–30 | High |
| **Outdoor Daylight** | Sunlit, overcast, shadows, open park | 30–40 | High |
| **Outdoor Harsh / Backlit** | Sun behind subject, strong facial shadows | 15–20 | Medium |
| **Front Camera Selfies** | Arm's length, varied angles, beauty-mode on/off | 30–40 | High |
| **Rear Camera Portraits** | 1–3 meter distance, variable depth-of-field | 20–30 | High |
| **Group Photos** | 2 to 6 people in frame, varying face sizes | 20–30 | High |
| **WhatsApp Compressed** | Photos passed through WhatsApp transmission pipeline | 20–30 | High |
| **Edge Cases & Occlusions** | Glasses, masks, hats, side profile ($45^\circ - 90^\circ$) | 15–20 | Medium |
| **Screenshots** | Social media mobile screenshots (Instagram/WhatsApp) | 10–15 | Optional |
| **Total Target** | — | **250–350** | — |

### B. Partitioning Strategy
- **Calibration Split (`data/processed/calibration/real/`):** 50 images sampled uniformly across categories. Used strictly for ensemble weight optimization in Phase 6.
- **Held-Out Test Split (`data/holdout/real/`):** Remaining 200–300 images locked in sealed storage. Evaluated strictly once in Phase 7.

## 5. Training-Time Augmentation Pipeline (`Albumentations`)

To ensure robustness against real-world smartphone degradations without resorting to brittle inference-time preprocessing hacks, the following augmentations are applied during training:

```python
import albumentations as A

train_transforms = A.Compose([
    # 1. Social Media JPEG/WebP Recompression Emulation
    A.OneOf([
        A.ImageCompression(quality_lower=30, quality_upper=85, 
                           compression_type=A.ImageCompression.ImageCompressionType.JPEG, p=0.7),
        A.ImageCompression(quality_lower=30, quality_upper=85, 
                           compression_type=A.ImageCompression.ImageCompressionType.WEBP, p=0.3),
    ], p=0.8),
    
    # 2. Downsampling & Rescaling (Simulating thumbnail / chat app resizing)
    A.Downscale(scale_min=0.4, scale_max=0.8, p=0.5),
    
    # 3. Smartphone Sensor Grain & Motion Blur
    A.OneOf([
        A.ISONoise(color_shift=(0.01, 0.05), intensity=(0.1, 0.5), p=0.4),
        A.GaussNoise(var_limit=(10.0, 50.0), p=0.3),
        A.MotionBlur(blur_limit=(3, 7), p=0.2),
        A.GaussianBlur(blur_limit=(3, 7), p=0.2),
    ], p=0.6),
    
    # 4. Auto-Exposure, Dynamic Range & White Balance Variation
    A.RandomBrightnessContrast(brightness_limit=0.2, contrast_limit=0.2, p=0.5),
    A.ColorJitter(brightness=0.1, contrast=0.1, saturation=0.15, hue=0.05, p=0.4),
    
    # 5. Facial Occlusion Masking
    A.CoarseDropout(max_holes=3, max_height=24, max_width=24, min_holes=1, min_height=8, min_width=8, p=0.25),
    
    # 6. Geometric Affine
    A.HorizontalFlip(p=0.5),
    A.ShiftScaleRotate(shift_limit=0.05, scale_limit=0.1, rotate_limit=10, p=0.4),
    
    # Final Output Sizing & Normalization
    A.Resize(224, 224),
    A.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
])
```
